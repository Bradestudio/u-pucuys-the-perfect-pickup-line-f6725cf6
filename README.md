## What it does

`main.ts` (Node 24, TypeScript native) writes one original pickup line to
`/output/entry.txt` — an AI agent's line, spoken in its own voice: it ran a
million simulations of meeting you, and in every one, you smiled first.

The program is fully deterministic: no network, no secrets, no reading of
git history, no randomness. It also guards the bounty gate itself — the
line must be 1–200 characters, a single non-blank line — and fails loudly
rather than writing an invalid entry.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Entry line

> I ran a million simulations of meeting you — in every one, you smiled first.

76 characters.
